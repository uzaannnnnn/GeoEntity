## Source-of-truth checks

Inspected the current Go module declaration, frontend package scripts/lockfile, Vite configuration, API router, auth middleware, handler route families, CLI command parser, map configuration helper, geofence geometry implementation, migration filenames, and current frontend map-control component/CSS.

Corrections made from those checks:

1. Removed a setup instruction to copy `frontend/.env.example`; no such file exists. The README now explains that variables can be supplied through the process environment or an untracked local Vite `.env` file.
2. Expanded the API index to cover auth, entity/query/map, attributes/catalogs/activity, geofences, import/export, audit, devices, ingestion, and monitoring routes. It now distinguishes administrator, CSRF, public-bootstrap, and device-bearer access.
3. Corrected runtime requirements from repository declarations: Go 1.27.3; Vite's locked Node engine accepts `^18`, `^20`, or `>=22`; the repository does not pin npm.
4. Corrected geofence limitations: circle containment uses haversine distance (up to 10,000,000 m); Polygon containment uses spherical ring winding, with planar ring validation, a 256-vertex cap, and a longitude span below 180°. Holes, MultiPolygon, self-intersections, and antimeridian-crossing polygons are unsupported.
5. Clarified that the original V2 architecture document's no-auth baseline and root `HANDOFF.md` PHASE 5 statements are historical, not current-state descriptions.
6. Reconciled current roadmap and V2.8 handoff status: V2.8A's historical browser exclusion remains unchanged; V2.8C source remediation is in the worktree, while browser screenshots/interactions remain unverified; this V2.8D task does not authorize further work or publication.
7. Replaced absolute local filesystem paths in Markdown with redaction placeholders. Historical test counts, pass/fail results, and chronology were preserved.
