## Findings and fixes

### V27C-01 — Entity deletion with revoked devices

`SQLite.Delete` now selects every device whose `entity_id` references the entity, independent of `status`. In the same transaction it revokes any still-active credentials, sets each retained device tombstone to detached with no entity association, preserves an existing device revocation timestamp, records the existing lifecycle audit event, and deletes the entity. Device rows and immutable observation snapshots remain in place. A failed detach still rolls back lifecycle changes, audits, and the entity delete together.

`device_entity_delete_test.go` covers active, revoked, mixed, associated-detached, and unrelated already-detached devices; credential revocation and preserved original revocation time; preserved observations; foreign-key integrity; and injected failure after an earlier device update to verify full rollback.

### V27C-02 — Backup manifest schema version

`backup.Create` now reads the database's maximum migration version and validates the exact migration ledger before producing a manifest. Verification returns the schema version established by the existing integrity, foreign-key, migration-ledger, and trigger checks, then rejects a manifest/database mismatch with both versions in the error. `Restore` uses `Verify` before it writes a candidate or touches the target. Schema-6 backup verification and restore-forward compatibility remain supported.

Backup tests cover schema-7 creation and verification, schema-6 verification and restore, schema-7/schema-6 and schema-6/schema-7 mismatches, invalid schema metadata, and preserving an existing target when restore rejects a mismatch.

### V27C-03 — Production history query plan

Added `monitoring.HistoryQuery`, used directly by the history HTTP handler and the query-plan test. Optional sensor and cursor predicates are included only when supplied, with all values bound as parameters. The test runs `EXPLAIN QUERY PLAN` over this exact production query and checks the entity/time index for unfiltered history and the entity/sensor/time index for a sensor-filtered cursor page.
