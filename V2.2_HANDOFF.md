## 1. Implementation Summary

1. **Feature A — Marker Clustering:**
   - Implemented [`EntityMarkerLayer`](frontend/src/components/map/EntityMarkerLayer.tsx) using `react-leaflet-cluster` (v4.1.3).
   - Only persisted entities are clustered; draft location and user location layers are rendered strictly outside the cluster group.
   - Preserves entity IDs as stable React keys (`key={entity.id}`) and retains existing custom SVG pin icons, tooltips, and popups.
   - Custom cluster count bubbles with size tiers: small (<10), medium (10–99), and large (100+).
   - Selection synchronization: selecting an entity from the sidebar while its marker is inside a collapsed cluster calls `clusterGroup.zoomToShowLayer(marker, callback)`, expanding the cluster and centering the marker while preserving the selection halo and detail panel.

2. **Feature B — Locate Me (Browser Geolocation):**
   - Implemented via [`geolocation.ts`](frontend/src/utils/geolocation.ts) and [`UserLocationLayer`](frontend/src/components/map/UserLocationLayer.tsx).
   - **Strict Privacy Enforced:** One-shot `navigator.geolocation.getCurrentPosition` triggered exclusively by explicit user button click. Never runs on page load, never uses `watchPosition`, never writes to `localStorage` or `sessionStorage`, and never transmits coordinates to the backend API or entity store.
   - Renders a distinct blue pulsating location marker and translucent accuracy radius circle.
   - Comprehensive error handling: maps `PERMISSION_DENIED`, `POSITION_UNAVAILABLE`, `TIMEOUT`, and `UNSUPPORTED` to accessible, actionable user feedback.

3. **Feature C — Fit All Entities:**
   - Implemented pure bounding box and coordinate validation helper in [`mapBounds.ts`](frontend/src/utils/mapBounds.ts).
   - Validates finite geographic ranges (`lat in [-90, 90]`, `lng in [-180, 180]`).
   - Zero valid points: button disabled, displays informational feedback, camera is not moved.
   - Single valid point: centers on the point with zoom capped at `min(13, maxZoom)`.
   - Multiple valid points: fits bounds with 44px padding and max zoom capped at `min(14, maxZoom)`.
   - Identical coordinates: treated as a single spatial extent without dropping markers.
   - Non-destructive: does not modify or clear selected entity, side panel, or draft state.

4. **Feature D — Map Legend:**
   - Implemented collapsible [`MapLegend`](frontend/src/components/map/MapLegend.tsx) panel.
   - Accurately mirrors real visual tokens:
     - Entity types (Vehicle, IoT Device, Facility, Other) using exact SVG glyphs from [`markerIcons.ts`](frontend/src/components/map/markerIcons.ts).
     - Entity statuses (Active, Maintenance, Inactive) using real CSS status dots.
     - Map symbols: Selected halo indicator, cluster count bubble, current user location dot + accuracy radius, and draft placement marker.
   - Accessible disclosure with `aria-expanded` and `aria-controls`.

5. **Feature E — Coordinate Inspector:**
   - Implemented [`CoordinateInspector`](frontend/src/components/map/CoordinateInspector.tsx).
   - Displays map center latitude and longitude formatted to 6 decimal places (e.g. `-6.208800, 106.845600`).
   - Updates smoothly on Leaflet `moveend` (never on every pointer event).
   - Copy button formats exactly as `latitude, longitude` with clipboard fallback and screen-reader announcement (`role="status"`, `aria-live="polite"`). Never formatted or labeled as GeoJSON.
   - Does not mutate selected entity, draft state, or backend data.

6. **Feature F — Advanced Map Controls Toolbar:**
   - Implemented compact [`MapToolbar`](frontend/src/components/map/MapToolbar.tsx) in the upper-right corner.
   - Native accessible `<button>` elements with keyboard focus indicators, `aria-label`, `aria-expanded`, and disabled states.
   - Event propagation disabled (`stopPropagation`) to prevent toolbar clicks from inadvertently triggering location-picker map clicks.
   - Positioned to prevent overlapping top-left zoom controls, top-center location picker banner, or bottom-right OSM attribution.

## 8. Manual Browser Verification Procedure

*Limitation note: As the development environment lacks an integrated browser automation harness (e.g. Playwright/Puppeteer), the 20-step verification was formulated as a reproducible manual test checklist for human reviewer verification on desktop and mobile viewports:*

1. **Empty map:** Start with 0 entities; verify Fit All is disabled with accessible title.
2. **One entity:** Click Fit All; verify map flies to point at zoom 13.
3. **Multiple sparse entities:** Click Fit All; verify camera bounds fit all valid coordinates with padding.
4. **Dense cluster:** Zoom out; verify cluster bubble displays count matching contained entities.
5. **Identical coordinates:** Seed 2 entities with identical lat/lng; verify they cluster and spiderfy at max zoom.
6. **Cluster click:** Click a cluster; verify smooth zoom to cluster bounds.
7. **Sidebar selection reveal:** Select an entity from the sidebar that belongs to a collapsed cluster; verify cluster expands and marker is centered with selection pulse.
8. **Editing coordinates:** Move an entity via form; verify marker updates position in cluster upon save.
9. **Deleting an entity:** Delete a clustered entity; verify cluster count decrements immediately.
10. **Refresh:** Click refresh; verify no duplicate markers appear.
11. **Draft marker separation:** Click "Add Entity" and click map; verify draft pin appears with cyan ripple outside clusters.
12. **Locate Me permission prompt:** Click Locate Me; verify browser requests permission.
13. **Locate Me denied:** Deny permission; verify accessible error pill ("Location access was denied").
14. **Locate Me success:** Allow permission; verify blue pulsing marker and accuracy circle appear; map flies to user location.
15. **User location reload:** Refresh page; verify user location dot disappears (ephemeral memory state).
16. **Coordinate Inspector:** Pan map; verify latitude and longitude update to 6 decimals on moveend.
17. **Coordinate copy:** Click Copy Coordinates; verify clipboard receives `lat, lng` and "Copied!" feedback displays.
18. **Legend toggle:** Click Legend; verify panel expands displaying all types, statuses, cluster bubble, and draft pin.
19. **Keyboard navigation:** Tab through toolbar, legend, and inspector; verify visible focus rings.
20. **Responsive layout:** Test at 400px width; verify controls, legend, and inspector fit within upper map region without overlapping attribution.
